# 本草知体（AI中医舌诊体质APP）

轻量化、平民化 AI 中医健康自测工具

**在线安装指南**：见 [INSTALL.md](./INSTALL.md)

## 产品定位
- 拍照舌象 AI 诊断 + 九种体质测评 + 个性化中医养生方案
- 无医疗诊断资质，仅做健康参考与养生科普

## 功能（V1.0 MVP）
1. **AI舌诊拍照诊断**（核心）
   - 上传/拍摄舌头照片
   - 模拟 AI 识别舌质、舌苔、舌形
   - 生成完整体质报告 + 调理方案

2. **九种体质自测问卷**
   - 基于国标《中医九种体质分类判定标准》
   - 18题简易版 + 雷达图展示

3. **健康档案**
   - 本地存储历史舌诊与问卷记录
   - 支持查看历史报告

4. **养生知识库**
   - 四季养生、食材功效、穴位科普、体质专项

5. **个人中心**
   - 隐私政策、用户协议、关于我们

## 快速开始

### 1. 本地体验
下载本仓库的 `index.html`（完整 APP 文件），用手机浏览器直接打开即可。

或：
```bash
git clone https://github.com/sandy01384007/bencao-zhiti-app.git
cd bencao-zhiti-app
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 2. 部署到 Vercel
1. 登录 vercel.com → New Project
2. 导入本仓库
3. Framework 选 Other，直接 Deploy
4. 获得在线链接，手机可「添加到主屏幕」

详细步骤见 [INSTALL.md](./INSTALL.md)

## UI 规范
- 主色：茶绿色 `#4A7C59`
- 风格：新中式极简国风 + 医疗柔和风
- 全部圆角卡片、低饱和度阴影

## 风险规避
- 所有页面带免责声明
- 结果仅用“体质、偏颇、亚健康、养生建议”
- 不接入问诊、不开处方、不卖药
