# 本草知体（AI中医舌诊体质APP）

轻量化、平民化 AI 中医健康自测工具

## 产品定位
- 拍照舌象 AI 诊断 + 九种体质测评 + 个性化中医养生方案
- 无医疗诊断资质，仅做健康参考与养生科普

## 功能（V1.0 MVP）
1. **AI舌诊拍照诊断**（核心）
   - 上传/拍摄舌头照片
   - 模拟 AI 识别舌质、舌苔、舌形
   - 生成完整体质报告 + 调理方案

2. **九种体质自测问卷**
   - 基于国标《中医九种体质分类判定标准》
   - 18题简易版 + 雷达图展示

3. **健康档案**
   - 本地存储历史舌诊与问卷记录
   - 支持查看历史报告

4. **养生知识库**
   - 四季养生、食材功效、穴位科普、体质专项

5. **个人中心**
   - 隐私政策、用户协议、关于我们

## 使用方法
直接用手机浏览器打开 `index.html` 即可，或部署到任意静态服务器。

推荐：
- 用手机 Chrome / Safari 打开
- 添加到主屏幕，体验接近原生 APP

## UI 规范
- 主色：茶绿色 `#4A7C59`
- 风格：新中式极简国风 + 医疗柔和风
- 全部圆角卡片、低饱和度阴影

## 风险规避
- 所有页面带免责声明
- 结果仅用“体质、偏颇、亚健康、养生建议”
- 不接入问诊、不开处方、不卖药

## 后续迭代（V1.1）
- 真实 AI 模型接入（可参考开源项目 TongueDiagnosis）
- 每日养生打卡
- 体质变化趋势图
- 分享海报生成
- 方案收藏

## 技术说明
纯前端实现（HTML + CSS + JS），无后端依赖。
舌诊结果为演示模拟，正式产品需接入真实视觉模型 + 大模型解读。
